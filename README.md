# Accent Guessr

A daily accent-guessing game. Five real voices a day: listen, then guess where each speaker is from. Three guesses per voice with progressive hints, a practice mode, streaks, and a shareable score.

Play it: https://lukaswall.github.io/accent-guessr/

## Audio
