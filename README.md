# Accent Guessr

A daily accent-guessing game. Five real voices a day: listen, then guess which accent each speaker has. Five turns per voice: each guess or "Next clue" uses one turn and reveals one more clue (world region, then letters of the accent name), then the answer, an endless mode, a practice mode, a map-guess mode (tap the world map where you think the accent belongs; proximity decides), a quick-pick mode (four written options per voice), fixed-length short modes (2, 3 or 5 seconds of every voice), and a hard mode that starts you with 2 seconds of audio and unlocks more of the same clip (3 s, 5 s, full) as you guess or tap Next clue. The player shows the unlocked time, playback progress, and has play/pause and replay-from-start controls. After each reveal a world map highlights the place the answer label is named after. Streaks and a shareable score.

Play it: https://lukaswall.github.io/accent-guessr/
